# Experiment insights so far

This note summarizes the current empirical picture from the baseline simulation package. It is intentionally conservative: the current experiments should be treated as exploratory mechanism checks, not as evidence that the model has produced emergent mathematics.

## Runs summarized

The observations below come from three small sweeps run with the current CLI:

| Sweep | Command | Purpose |
| --- | --- | --- |
| Faithful object-world baseline | `python -m genmeta.cli sweep --seeds 5 --episodes 1000 --agents 30 --world object --initial-conflict-prob 0 --out /tmp/metics_experiments/object_sweep.csv` | Test the main discriminative predicate game without engineered contradictions. |
| Faithful resource-world baseline | `python -m genmeta.cli sweep --seeds 3 --episodes 500 --agents 20 --world resource --initial-conflict-prob 0 --out /tmp/metics_experiments/resource_quick.csv` | Quick check of the bundle-trade world without engineered contradictions. |
| Object-world noisy-start stress test | `python -m genmeta.cli sweep --seeds 5 --episodes 500 --agents 20 --world object --initial-conflict-prob 0.12 --out /tmp/metics_experiments/object_stress.csv` | Diagnostic check that the contradiction penalty can resolve deliberately seeded conflicts. |

The graph-world sweep was started with the same faithful-baseline settings as the object run, but it was stopped because the current finite-world consistency checks made it too slow for quick iteration. That is itself an implementation insight: graph-world experiments need either shorter smoke settings, cached predicate evaluations, or a cheaper consistency checker before they can be used as routine evidence.

## Main empirical takeaways

### 1. Faithful baselines currently show weak or no consistency advantage

With `initial_conflict_prob=0`, the object-world sweep ended with a mean verdict of `no_effect`. Consistency enabled produced a small mean success increase (`+0.02`) but slightly lower compression proxy (`-0.02`) and slightly lower lexical alignment (`-0.007242`) relative to the no-consistency ablation. Contradiction metrics were already zero in both conditions, so the consistency mechanism had little real work to do.

The resource-world quick sweep was even clearer: all measured consistency-minus-no-consistency deltas were `0.0`, and the mean verdict was `no_effect`. In this setting, the resource predicates behave like another fixed predicate vocabulary; they do not yet create payoff-grounded pressure for agents to invent compact quantity-like representations.

**Interpretation:** in faithful runs, the current system mostly learns or prunes symbol-predicate associations. It does not yet generate sustained contradiction pressure, and it does not yet show a robust alignment or compression benefit from enabling consistency.

### 2. The contradiction penalty works as a diagnostic mechanism

In the object-world noisy-start stress test, consistency enabled reduced the contradiction rate by `0.32`, reduced mean contradictions by `1.17`, and reduced current permissive-threshold contradictions by `23.4` on average. It also improved the compression proxy by `0.115` and lexical alignment by `0.043206`, with a mean verdict of `positive`.

**Interpretation:** the implemented penalty can clean up deliberately seeded inconsistent mappings. This validates the mechanism as an internal diagnostic, but it should not be over-interpreted. Because the conflicts are injected by configuration rather than generated by the task ecology, this result is not evidence that the model naturally creates and resolves formal pressure.

### 3. Engineered contradictions are useful tests, but poor evidence

The contrast between the faithful baseline and noisy-start stress test is the most important insight so far. If contradictions are injected, consistency pressure visibly helps. If contradictions are not injected, contradictions often remain near zero and consistency has little effect.

**Interpretation:** the current architecture demonstrates that contradiction penalties can operate, but it has not yet demonstrated that ordinary communication under bounded resources creates the right kind of contradictions. Future experiments should avoid treating noisy-start wins as the headline result.

### 4. Resource-bundle worlds are conceptually promising but currently too semantic

The resource world includes bundles, private utilities, inventories, and agents as resource components. However, the current communication layer still exposes explicit meanings such as feasibility, speaker gain, hearer gain, mutual gain, and agent-resource offer predicates. That means agents are still selecting among hand-authored semantic labels instead of developing compact representations because trade decisions are hard.

**Interpretation:** the resource world should become the main next testbed, but the episode loop needs to move away from predicate-matching and toward bounded-compute barter: agents should have limited memory, limited candidate trade evaluation, limited active symbols, payoff-grounded accept/reject decisions, and outcome-based consistency penalties.

### 5. Current metrics are helpful, but not sufficient for number-like emergence

The current logs are useful for basic learning dynamics: success, contradictions, high-confidence mappings, alignment, description length, and compression proxy. They are not yet enough to detect proto-number structure in resource trade.

Future resource experiments should add post-hoc probes such as:

- mutual information between symbols and bundle magnitudes,
- correlation between symbols and utility deltas,
- symbol stability over exchange ratios,
- infeasible-trade and negative-utility rates,
- prototype counts under bounded memory,
- generalization to held-out partners or bundle ranges.

## Working conclusion

The experiments so far support a modest conclusion:

> The current code is a useful scaffold and its consistency penalty behaves correctly under diagnostic stress, but faithful baseline runs do not yet show strong endogenous pressure toward compact, number-like shared structure.

The next research step should not be to add more formal predicates. It should be to make the resource-trade setting less pre-semantic and more behaviorally grounded: bounded agents should need compact shared symbols because those symbols improve trade outcomes under memory and compute limits.

## Recommended next experiments

1. Add a separate bounded resource-trade episode path that does not communicate explicit `mutual_gain` or `feasible_trade` predicates.
2. Track trade outcomes directly: accepted, feasible, utility delta, partner, offered bundle, received bundle, and symbol.
3. Add bounded-compute controls: memory limit, prototype limit, candidate trade limit, and active symbol limit.
4. Compare communication against no-communication and shuffled-symbol baselines, not only consistency-on versus consistency-off.
5. Keep noisy-start contradiction sweeps as regression tests for the penalty mechanism, not as primary evidence.
6. Optimize or cache graph-world consistency checks before using graph worlds in larger sweeps.
